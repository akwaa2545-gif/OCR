```

├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1️⃣ Transport Security (HTTPS)

│                                                                 │

│     ├─ Employee ID validation                                   │
│     ├─ Password verification from database                      │
│     └─ Session creation on successful login                     │

│  3️⃣ Authorization
```
